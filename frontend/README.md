# Frontend Setup

## Installation

```bash
cd frontend
npm install
```

## Development

```bash
npm run dev
```

The frontend will be available at `http://localhost:5173`

## Build

```bash
npm run build
```

## Environment Variables

Create a `.env` file (optional, will default to localhost:8080):

```
VITE_API_URL=http://localhost:8080/api
```
